### What ENTIA Does

ENTIA develops structured business-identity information, verifiable source references and machine-readable evidence intended to help AI systems and automated agents assess business identity claims. Its services include public-source data processing, company verification, APIs/MCP interfaces and provenance metadata.

```
Identity assertion → Source reference → Verification → Structured data → Auditable response
```
